# GuardStep logo files

SVG files are the master assets. PNG files are provided for software and services that do not accept SVG.

| File | Use |
| --- | --- |
| `guardstep-logo.svg` | Primary logo on a light background |
| `guardstep-logo-on-dark.svg` | White logo on a dark background |
| `guardstep-logo-monochrome.svg` | Black one-color logo |
| `guardstep-mark.svg` | Bracketed symbol without the wordmark |
| `guardstep-mark-32.svg` | Simplified symbol for rendering at 32px |
| `guardstep-mark-16.svg` | Simplified symbol for rendering at 16px |
| `guardstep-wordmark.svg` | Wordmark without the symbol |

Matching PNG files use the same names. The small PNG marks are exactly 32×32 and 16×16 pixels.

## Colors

- GuardStep blue: `#0060CD`
- GuardStep ink: `#26343C`
- Monochrome: `#000000`
- On dark: `#FFFFFF`

Keep the original proportions. Use the supplied monochrome variants instead of recoloring the primary artwork.
